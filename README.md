# Asteroid Recycler

Итоговый проект по дисциплине **«Программирование игр»**, МАИ.


Top-down аркада на Unity 6 / URP про дрон-утилизатор, который сортирует астероиды по приёмным секторам и разбивает крупные обломки заряженным магнитным импульсом.

## Описание игры

Игрок управляет колёсным дроном-вездеходом, оснащённым магнитной пушкой, и работает на круглой утилизационной арене, в которую со всех сторон сыплются астероиды трёх типов:

- **Лёд** (голубой) — самый «слабый» тип
- **Металл** (жёлтый) — крепче
- **Камень** (красный) — самый прочный

По периметру арены установлены три приёмных сектора соответствующих цветов. Цель — отправлять астероиды в сектор «своего» цвета: попадание в правильный сектор начисляет очки, а в неправильный — отталкивает астероид обратно на поле.

Астероиды прилетают **крупными** — сначала такой обломок надо **раздробить магнитной пушкой** на мелкие фрагменты, и только потом маленькие куски можно сортировать по секторам. Магнитная пушка работает в двух режимах: притягивает астероиды к курсору и заряженным импульсом раскалывает крупные обломки.

Со 2-го уровня появляются **опечатанные астероиды** — серые «закрытые» обломки, которые нельзя ни разбить, ни сразу сдать. Над таким астероидом крутится цветной маркер, который показывает, в какой именно сектор его сначала нужно завезти, чтобы «разблокировать». На 3-м уровне попадаются двухстадийные опечатанные: после первого посещения маркер меняет цвет, и нужно завезти астероид ещё в один сектор.

Игра состоит из трёх уровней нарастающей сложности. Каждый уровень — это волна из фиксированного числа астероидов; новый уровень начинается только после того, как все астероиды текущей волны убраны с арены. После прохождения третьего уровня игрок видит экран **MISSION COMPLETE** с итоговым счётом, лучшим комбо, числом сортировок и возможным новым рекордом.

## Игровые механики

- **Дрон игрока** — ездит по арене с инерцией и максимальной скоростью, умеет ускоряться (boost), плавно поворачивается по направлению движения; на крыше — независимая турель, которая всегда смотрит на курсор.
- **Магнитное притяжение** — пока зажат `Space`, ближайшие к курсору астероиды плавно подтягиваются к нему: удобно собирать обломки в кучу или подтаскивать к нужному сектору.
- **Заряженный импульс** — `ЛКМ` зажимается, чтобы накопить заряд, и отпускается для выстрела. Импульс отталкивает астероиды от дрона, а **полный заряд раскалывает крупный астероид** на несколько маленьких.
- **Три типа астероидов** — лёд, металл и камень: у каждого свой цвет, свой сектор и уникальная процедурная форма (двух одинаковых обломков не бывает).
- **Опечатанные астероиды** — серые обломки с цветным маркером сверху: их нужно сначала завезти в сектор маркера, чтобы они «открылись», и уже после этого разбивать и сортировать как обычные. На 3-м уровне встречаются двухстадийные — требуют двух разных секторов подряд.
- **Сортировочные сектора** — три цветные приёмные зоны по периметру арены: принимают только маленькие астероиды своего цвета, всё остальное (другой цвет, крупный обломок, не разблокированный опечатанный) отбрасывают обратно на поле.
- **Очки и комбо** — за каждую правильную сортировку даются очки; если успевать сортировать астероиды без больших пауз, растёт комбо-множитель к награде. Лучший результат сохраняется между запусками.
- **Состояния игры** — стартовое меню с подсказками, основная игра, пауза по `Esc`, экран победы после 3-го уровня и мгновенный рестарт по `R`.
- **VFX и обратная связь** — частицы при дроблении, сортировках, попаданиях и отскоках от стен арены; пыль и искры от ударов; дрожание камеры через **Cinemachine** при выстрелах и расколах; светящиеся материалы на турели, луче импульса, шлейфе двигателя и маяках секторов.

## Управление

| Клавиша        | Действие                                                       |
|----------------|----------------------------------------------------------------|
| `W` `A` `S` `D` / стрелки | Движение дрона                                       |
| `Left Shift`   | Ускорение                                                      |
| `Space`        | Магнитное притяжение астероидов к курсору (удерживать)         |
| `ЛКМ`          | Зажать → отпустить — выпустить заряженный импульс              |
| `Esc`          | Пауза / возврат в игру                                         |
| `R`            | Рестарт уровня                                                 |
| `Enter` / `Space` | Старт игры из главного меню                                 |

## Уровни

В игре три уровня; переход на следующий уровень происходит автоматически, как только все астероиды текущей волны убраны с арены.

| Уровень | Размер волны | Опечатанные | Особенности                                          |
|---------|--------------|-------------|------------------------------------------------------|
| **1**   | 50           | нет         | Мягкий старт (15 с пониженного темпа), знакомство с механиками. |
| **2**   | 80           | ~35%        | Появляются одностадийные опечатанные астероиды.      |
| **3**   | 120          | ~60%        | Высокий темп спавна, ~45% опечатанных — двухстадийные. |

Помимо размера волны, по уровням ускоряется темп спавна и растёт максимальное число одновременно живущих астероидов на арене. На HUD'е отображается прогресс `LEVEL n/3`, а в момент ожидания зачистки — счётчик оставшихся астероидов.

## Технический стек

- **Unity 6** (`6000.4.5f1`)
- **Universal Render Pipeline (URP)** `17.4.0` — Lit / Particles Unlit материалы, HDR-эмиссия
- **New Input System** `1.19.0` — опрос клавиатуры и мыши
- **Cinemachine** `3.1.6` — камера-шейк через Impulse Source
- **C#** — скрипты разделены по неймспейсам:
  - `Game.Core` — менеджер игры, экраны, камера-шейк, score-popup
  - `Game.Player` — контроллер дрона, процедурная сборка ровера, шлейф двигателя, top-down-камера
  - `Game.Magnet` — притяжение, заряд и выстрел импульса, частицы-всплески, визуал заряда
  - `Game.Asteroids` — астероиды, типы, процедурная деформация мешей, спавнер с уровнями
  - `Game.Sectors` — приёмные сектора и их визуальное оформление
  - `Game.Arena` — эффекты столкновений со стенами

Графика и UI:
- HUD, стартовое меню, оверлеи паузы и победы — на **IMGUI** (без отдельных UI-префабов).
- 3D-модель дрона и оформление секторов **строятся процедурно из примитивов** в рантайме.
- Меш каждого астероида — **процедурно деформированная сфера** (Perlin-noise FBM + domain warping + кратеры + плоская закраска).
- Сохранение рекорда — `PlayerPrefs`.

## Как запустить

### Требования

- **Unity 6** (`6000.4.5f1`) — рекомендуется поставить ровно эту версию через **Unity Hub**, чтобы не было миграций пакетов.
- ОС: macOS / Windows / Linux (проект разрабатывался под macOS).
- Git (для клонирования).

### Запуск из редактора

1. Клонировать репозиторий:
   ```bash
   git clone <url-этого-репозитория>
   cd game-dev
   ```
2. Открыть **Unity Hub** → **Add** → выбрать корневую папку проекта (`game-dev`).
3. Открыть проект в Unity `6000.4.5f1`. Hub при первом запуске сам подтянет пакеты из `Packages/manifest.json`.
4. В окне **Project** открыть сцену `Assets/Scenes/Arena.unity`.
5. Нажать **Play** (`▶`) в редакторе.
6. На стартовом экране — `Space` или `Enter`, чтобы начать.

### Подсказки по геймплею

- Голубые льдины — слабые, жёлтый металл крепче, красный камень — самый прочный.
- Серые опечатанные астероиды нужно сначала завезти в подсвеченный сектор, и только потом разбивать.
- За серию подряд правильных сортировок растёт комбо-множитель к очкам — старайтесь не разрывать цепочку дольше двух с половиной секунд.
